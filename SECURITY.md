# Security

The integration must never be able to trade or move money, and must never store or leak the PIN or the session. A problem with either is a security problem.

## Reporting

Report it privately with **[Report a vulnerability](https://github.com/flaviorighi/ha-trade-republic/security/advisories/new)** in the Security tab, not in a public issue. Describe what can happen and how; leave out the details of your account.

This is a project maintained in spare time, so an answer can take a few days. Once the fix is released, the advisory is published, with credit to you if you want it.

## Supported versions

Only the latest release gets fixes. Update through HACS, or from the [releases](https://github.com/flaviorighi/ha-trade-republic/releases).
